# Study Tracker CLI

Python 소프트웨어 엔지니어링 기초를 연습하며 만든 터미널 기반 학습 기록 관리 프로그램입니다.
학습 기록을 추가·검색·삭제할 수 있으며, 기록은 SQLite 데이터베이스에 저장되어
프로그램을 다시 실행해도 유지됩니다.

## 주요 기능

- 학습 기록 추가 및 전체 조회
- 과목별 기록 검색
- 총 공부 시간 계산
- 개별 기록 삭제
- 전체 기록 초기화 및 취소 확인
- SQLite 데이터베이스 저장
- 데이터베이스 오류 로깅
- 공부 시간과 날짜 입력 검증

## 실행 화면

```text
=== 학습 기록 관리 ===
1. 기록 추가
2. 기록 조회
3. 총 공부 시간
4. 기록 삭제
5. 과목별 기록 검색
6. 기록 초기화
0. 종료
선택:
```

## 프로젝트 구조

```text
.
├── main.py                   # 프로그램 실행 및 전체 흐름 제어
├── models.py                 # 학습 기록 데이터 모델
├── sqlite_storage.py         # SQLite 초기화·CRUD·집계
├── ui.py                     # 사용자 입력과 출력
└── tests/
    ├── conftest.py            # 공통 테스트 데이터와 DB fixture
    ├── test_main.py           # 프로그램 흐름과 오류 처리 테스트
    ├── test_sqlite_storage.py # SQLite 저장소 테스트
    └── test_ui.py             # 사용자 입력·출력 테스트
```

각 모듈은 다음과 같이 역할을 분리했습니다.

- `models`: 프로그램에서 사용하는 데이터 구조
- `sqlite_storage`: SQL을 이용한 기록 저장·조회·검색·삭제·집계
- `ui`: 사용자 입력과 화면 출력
- `main`: 각 모듈을 연결하고 데이터베이스 오류 처리 및 프로그램 흐름 제어

## 실행 방법

### 요구 사항

- Python 3.10 이상

저장소를 내려받은 뒤 프로젝트 디렉터리에서 실행합니다.

```bash
python main.py
```

SQLite는 Python 표준 라이브러리에 포함되어 있어 별도의 실행 의존성은 없습니다.
프로그램을 실행하면 `study_tracker.db` 파일이 자동으로 생성됩니다. 이 파일은 개인 학습
기록을 담고 있으므로 Git 추적 대상에서 제외됩니다.

## 테스트

개발 및 검사 도구는 다음 명령으로 설치할 수 있습니다.

```bash
python -m pip install -r requirements-dev.txt
```

전체 테스트와 정적 검사는 다음과 같이 실행합니다.

```bash
python -m pytest
python -m ruff check .
python -m mypy .
```

현재 21개의 자동 테스트가 다음 동작을 검증합니다.

- SQLite 데이터베이스와 테이블 초기화
- 기록 추가, 전체 조회 및 자동 ID 생성
- 과목별 검색과 개별 기록 삭제
- 총 공부 시간 집계와 빈 데이터 처리
- 전체 기록 초기화
- 데이터베이스 오류 로깅과 종료 처리
- 메뉴와 사용자 입력 검증
- 화면 출력 형식

테스트 과정에서는 다음 pytest 기능을 사용했습니다.

- `fixture`: 반복되는 테스트 데이터 준비
- `monkeypatch`: 터미널 입력 자동화
- `capsys`: 출력 내용 검증
- `tmp_path`: 실제 데이터에 영향을 주지 않는 임시 데이터베이스 테스트

## 학습 내용

- `dataclass`를 이용한 데이터 모델링
- 타입 힌트를 이용한 함수 인터페이스 명시
- UI·프로그램 흐름·데이터 저장소의 역할 분리
- SQLite 연결과 테이블 생성
- `INSERT`, `SELECT`, `DELETE`, `SUM`을 이용한 CRUD 및 집계
- 파라미터 바인딩을 통한 안전한 SQL 실행
- `COALESCE`를 이용한 빈 집계 결과 처리
- 예외 처리와 애플리케이션 로깅
- 정상·실패·경계 사례를 포함한 단위 테스트
- Red–Green–Refactor 방식의 TDD
- Ruff와 mypy를 이용한 코드 품질 검사
- 테스트 가능한 코드 구조 설계
