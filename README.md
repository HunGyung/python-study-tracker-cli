# Study Tracker CLI

Python 소프트웨어 엔지니어링 기초를 연습하며 만든 터미널 기반 학습 기록 관리 프로그램입니다.
학습 기록을 추가·검색·삭제할 수 있으며, 기록은 JSON 파일에 저장되어 프로그램을 다시 실행해도 유지됩니다.

## 주요 기능

- 학습 기록 추가 및 전체 조회
- 과목별 기록 검색
- 총 공부 시간 계산
- 개별 기록 삭제
- 전체 기록 초기화 및 취소 확인
- JSON 파일 저장 및 복원
- 공부 시간과 날짜 입력 검증

## 실행 화면

```text
=== 학습 기록 관리 ===
1. 기록 추가
2. 기록 조회
3. 총 공부 시간
4. 기록 삭제
5. 과목별 기록 검색
6. 기록 초기화
0. 종료
선택:
```

## 프로젝트 구조

```text
.
├── main.py          # 프로그램 실행 및 전체 흐름 제어
├── models.py        # 학습 기록 데이터 모델
├── services.py      # 추가·검색·삭제·계산 로직
├── storage.py       # JSON 저장·불러오기·초기화
├── ui.py            # 사용자 입력과 출력
└── tests/
    ├── conftest.py      # 공통 테스트 데이터
    ├── test_services.py # 서비스 로직 테스트
    ├── test_storage.py  # JSON 저장소 테스트
    └── test_ui.py       # 사용자 입력·출력 테스트
```

각 모듈은 다음과 같이 역할을 분리했습니다.

- `models`: 프로그램에서 사용하는 데이터 구조
- `services`: 입출력에 의존하지 않는 핵심 로직
- `storage`: 파일 영속성 처리
- `ui`: 사용자 입력과 화면 출력
- `main`: 각 모듈을 연결하고 프로그램 흐름 제어

## 실행 방법

### 요구 사항

- Python 3.10 이상

저장소를 내려받은 뒤 프로젝트 디렉터리에서 실행합니다.

```bash
python main.py
```

별도의 실행 의존성은 없습니다. 프로그램을 실행하면 `records.json` 파일이 자동으로 생성되며,
이 파일은 개인 학습 기록이므로 Git 추적 대상에서 제외됩니다.

## 테스트

테스트 실행에는 `pytest`가 필요합니다.

```bash
python -m pip install pytest
python -m pytest
```

현재 26개의 자동 테스트가 다음 동작을 검증합니다.

- ID 자동 생성과 공부 시간 계산
- 과목별 검색과 기록 삭제
- 기록 추가 및 연속 ID 생성
- JSON 저장·복원·초기화
- UTF-8 한글 데이터 보존
- 메뉴와 사용자 입력 검증
- 화면 출력 형식

테스트 과정에서는 다음 pytest 기능을 사용했습니다.

- `fixture`: 반복되는 테스트 데이터 준비
- `monkeypatch`: 터미널 입력 자동화
- `capsys`: 출력 내용 검증
- `tmp_path`: 실제 데이터에 영향을 주지 않는 파일 테스트
